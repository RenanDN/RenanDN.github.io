## 🚀 About the Project

This repository hosts the source code for my personal portfolio and professional CV. Designed with a focus on performance, accessibility, and clean design, it operates as a modern, zero-dependency static web application.

### 🎯 Key Features

- **🌐 Fully Bilingual (EN / PT):** Instant language toggling without page reloads using semantic HTML attributes and native CSS selectors.
- **🌓 Light / Dark Theme:** Automatic system preference detection (`prefers-color-scheme`) with persistent state via `localStorage`.
- **📄 Print & PDF Optimized CV:** Dedicated stylesheet (`cv.css` with `@media print` rules) engineered to export a crisp 2-page A4 document, consistently in light mode.
- **⚡ Zero Dependencies & High Performance:** Built purely with semantic HTML5, modern CSS3 design tokens, and Vanilla JavaScript.

---

## 🛠️ Built With

- **Structure:** Semantic HTML5
- **Styling:** Modern CSS3 (Custom Properties, Flexbox, Grid, Print Media Queries)
- **Logic:** Vanilla JavaScript (ES6+)
- **Persistence:** Web Storage API (`localStorage`)
